# 📊 Presentación FOL: Modalidades de Contratación

Presentación interactiva completa sobre **Modalidades de Contratación Laboral** según la normativa española vigente, elaborada por **Lidia Páez** para la asignatura de Formación en Orientación Laboral (FOL).

## ✨ Características

### 📖 Contenido Completo
- **12 diapositivas educativas** con toda la materia FOL
- Análisis exhaustivo de cada modalidad de contratación
- Imágenes profesionales en cada diapositiva
- Información estructurada y fácil de entender

### 🎮 Juego Interactivo
- **10 preguntas** sobre los temas tratados
- Opción múltiple con retroalimentación inmediata
- Sistema de puntuación automático
- Resultados detallados:
  - Preguntas correctas/incorrectas
  - Porcentaje de acierto
  - Mensajes personalizados según desempeño
  - Opción para reintentar

### ⚡ Funcionalidades Interactivas
- **🔍 Buscador integrado**: Busca por temas clave y salta a la diapositiva correspondiente
- **⛶ Pantalla completa**: Presenta en modo pantalla completa (tecla `F`)
- **⌨️ Controles por teclado**:
  - `←` `→` Navega diapositivas
  - `F` Pantalla completa
- **💡 Sistema de ayuda**: Acceso rápido a controles
- **📱 Responsive**: Adaptado para móviles y tablets

## 🎯 Contenido de las Diapositivas

1. **Portada** - Introducción
2. **El Contrato de Trabajo** - Definición y características
3. **Contratos Indefinidos** - Forma ordinaria
4. **Fijo Discontinuo** - Trabajos de temporada
5. **Por Circunstancias de Producción** - Temporal por demanda
6. **Contrato de Sustitución** - Cobertura de ausencias
7. **Encadenamiento y Fraude** - Protección legal
8. **Formación en Alternancia** - Aprendizaje combinado
9. **Práctica Profesional** - Para titulados recientes
10. **Tiempo Parcial** - Jornadas reducidas
11. **Relevo y Jubilación Parcial** - Rejuvenecimiento de plantillas
12. **Conclusión** - Síntesis y principios clave
13. **Juego Interactivo** - Evaluación de conocimientos

## 🚀 Cómo Usar

### Opción 1: En línea (Recomendado)
1. Abre [la presentación en línea](https://mulhacem-spec.github.io/presentacion-contratacion/) (cuando se habilite GitHub Pages)
2. ¡Disfruta!

### Opción 2: Localmente
1. Descarga el archivo `index.html`
2. Abre en tu navegador (Firefox, Chrome, Safari, Edge)
3. ¡Listo para usar!

## ⌨️ Controles

| Acción | Tecla/Botón |
|--------|------------|
| Siguiente diapositiva | `→` o botón ❯ |
| Diapositiva anterior | `←` o botón ❮ |
| Pantalla completa | `F` o botón ⛶ |
| Buscar tema | 🔍 barra de búsqueda |
| Ayuda | `?` botón |
| Jugar | Navega hasta la penúltima diapositiva |

## 🎮 Cómo Jugar

1. Navega hasta la penúltima diapositiva (Conclusión)
2. Presiona "SIGUIENTE" para acceder al juego
3. Lee la pregunta cuidadosamente
4. Selecciona una opción
5. Se mostrará la respuesta correcta
6. Presiona "Siguiente" para la próxima pregunta
7. Al terminar, verás tus resultados
